# 验收与 GPT 应用适配

## 一、分别验收

| 层次 | 检查内容 | 证据 |
|---|---|---|
| 项目结构 | 文件、入口、版本、引用、清单哈希 | 仓库内容与程序输出 |
| 程序合同 | v1兼容；v2身份、角度、尺度、类型、局部变更 | 实际 unittest 与命令行执行 |
| 提示词语义 | 完整回应请求；不默认性别年龄时代；无冲突 | 完整输入与输出逐项核对 |
| 实际图像 | 同脸、适龄、正侧背、服装左右、身材、手脚、真实像素 | 实際图片及可见偏差 |
| 应用保存与行为 | 导入后的完整指令、知识、工具开关与新对话行为 | 实际宿主会话 |

每层单独 PASS / FAIL / PARTIAL / UNVERIFIED。程序测试不能代替自然语言评测；自然语言评测不能代替真实图片；未执行的层保持 UNVERIFIED。

图像至少检查：恰好四列；特写不是第四个角色；严格0°/90°/180°；一侧不是镜像；三张全身同尺度和姿态；特写独立放大；头顶手脚完整；衣服结构和单侧标记正确；无未授权的年龄、性别表现、时代与身体变化。婴儿和受托人物保留必要支撑，标记被遮挡区域。发现具体偏差后只修相关变量；最多三轮有授权的定向返修，仍不合格明确保留失败状态，不无限重试。

## 二、导出

```bash
python3 scripts/export_gpt.py --out /absolute/path/outside-skill
```

instructions.txt 从同一 SKILL、决策、四视图、身份年龄时代规则生成；knowledge-lexicon.md 汇总面部结构、词表、妆容、两版检查说明和来源；app-config.json 提供名称、简介和开场白；export-manifest.json 记录源与输出哈希。程序只导出，不联网、登录或上传，不自动创建公开 GPT。

8000字符是本导出器为兼容既有合同采用的预算，不保证当前所有宿主限制相同。先检查当前宿主；不能静默截断关键规则。知识是补充材料，不应覆盖四视图与授权规则。

图片能力在导出配置中保留为可选开启；运行时仍按当前用户请求决定是否调用。没有该能力的宿主降级为文字，并明确未生图。适配后须在实际新会话测试普通设计、显式生图、引用命令、只改文字、儿童自然定妆及同脸换装。未经实际安装测试不得标称已经在所有平台验证。
