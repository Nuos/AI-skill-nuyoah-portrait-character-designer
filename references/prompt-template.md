# 完整中文提示词模板与输出合同

用户不用填写本表。执行者先把自然语言整理成具体选择，再交付一个完整提示词；不得把未替换占位符当成最终结果。可运行数据见 `examples/turnaround-plan.json`。

## 一、合成图的段落顺序

摄影质感 → 四列布局及目标像素 → 唯一人物身份与年龄 → 时代文化 → 身体结构与可选身高/头身比 → 肤质、毛发、妆容、服装、配饰 → 中性姿态及支撑 → 背景光线与同尺度 → 身份/服装锁定 → 参考证据与保守补全 → 精简画面约束。

模板的“特写／正面／侧面／背面”不能替换为四个不同人物；不能用四张证件照代替全身；不能裁掉手脚来迁就排版。默认浅中性摄影棚背景、柔和均匀光，不让戏剧性布景遮挡人物。角色的时代是造型设定，不要求把四视图搬到剧情场景中。

独立图提示词必须展开全部身份与服装基准，然后只保留本图的视角指令。不得写“同上一张”；不得把合成图的四列构图复制到单视图提示词。

## 二、可执行编译

```bash
python3 scripts/check_design.py examples/turnaround-plan.json
python3 scripts/build_prompt.py examples/turnaround-plan.json
python3 scripts/build_prompt.py examples/turnaround-plan.json --view side
```

脚本以结构化数据为输入，不执行自然语言理解。原始请求中的硬约束必须由执行者完整录入字段或 notes；程序通过不证明它们都已覆盖。对 fields、notes 与输出间的矛盾还需语义复核。

无图片工具时交付提示词即可，不制作伪图片。明确需要图片且宿主支持时，再将提示词和获得授权的参考图送入图片工具。工具不支持负面提示词字段时，将精简禁忌合并入正文；不虚构模型参数或 ComfyUI 工作流节点。

## 三、实际图像交付

默认生成一张四列合成定妆表。用户另外要求独立资产时，按特写、正面、侧面、背面交付四张并提供合成图；独立生成的三方向必须重新核对同一身份与尺度。不得未经核对就将四个独立人物拼接。

文件名建议 `人物编号_造型版本_视图_YYYYMMDD-HHMM.png`，时间戳采用明确时区。同步记录目标尺寸、实际像素、生成模型/版本、参考资产、是否后处理和图像审查结果；只记录实际使用过的参数。保留分辨率与视觉正确性两项验收，不以放大像素掩盖变脸或错肢。


## 四、词表消费与回归

`build_prompt.py`直接读取机器词表，不是只把范文附在文档末尾。每个视图重新按适用条件选取词条，并生成无重复负向词。人物设定来自计划字段；词表只补充摄影、几何与一致性语言，不重写性别年龄时代。

```bash
python3 scripts/build_prompt.py examples/myth-laborer-188.json
python3 scripts/build_prompt.py examples/myth-laborer-188.json --view portrait --negative-only
python3 scripts/randomized_smoke.py --seed 20260925 --count 24 --out /tmp/nuyoah-random-new
```

随机回归只写结构化计划和文本，输出目录必须为空；不调用付费生图。每组输出一个plan.json、一个合成图提示词及四个独立视图提示词。图像试测记录必须包含实际服务状态，不以随机文本数量代替图片数量。
